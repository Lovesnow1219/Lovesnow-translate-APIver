## 使用方式

- 在「配音節奏」保持配音語速 1.00，英文譯文字數預算預設 2.2。
- 「本片翻譯風格／需求」是自由文字，依影片調整。預設偏自然口語與喜劇對話，不定義特定作品角色或詞彙。
- 有清晰字幕的改梗動畫，可勾「以原片字幕為翻譯依據」。最多取樣 48 張畫面，長卡片加密取樣並保留起訖前後少量範圍；不同畫面的字幕引文與替換前後文字保存在 `source_subtitle_review.json`。此選項預設關閉，增加主審核 API 用量；確認原文改變後會重建相依譯文與配音。畫面上的拼字本身也可能有錯，語義仍需結合本片內容審核。
- 「整片播放倍率」控制畫面與聲音一起變速，通常維持 1.00。
- 原片底部已有字幕時，將「翻譯字幕位置」設為上方；目前為手動選擇，沒有自動字幕遮罩或去字。
- 到「配音時間軸」查看逐句原片開始、配音開始、時長與延遲。延遲 ≥ 0.8 秒是檢查提示，不是自動砍掉台詞的條件。
- 舊版已改錯的中文原文需手動更正或重新辨識；新版不會臆測還原舊資料。
- 譯文太長仍可能延遲。先修譯文；保持完整台詞，不為了追下一個時間點剪掉句尾。
- 改英文預算／風格僅影響之後的翻譯。要更新已存在譯文，勾「強制重翻」。舊譯文不會因升級自動全數改寫。
- 自動改譯覆核的逐卡接受／拒絕原因保存在審稿報告的 `rewrite_validation`。這是模型覆核紀錄，不能視為真人品質保證。被拒絕的提案保留供檢查，不改成另外一句來繞過覆核。
- 原文改寫的獨立覆核保存在 `source_repair_validation.json`。三類動作各自核准，不能因為一個錯字可修便同時接受刪句或換講者。模型只取得原文、鄰句與可見字幕證據；大綱推論不能作為獨立證明。

## 快取遷移與成本

舊版 WAV 沒有輸入指紋，無法證明是否對應目前的語速／文字／聲線。首次使用新版配音會重建這些舊音檔，可能產生供應商 API 費用。新版完成後，未變動且可驗證的音檔可以重用。配音參數存在每片 `dubbing_settings.json`，風格存在 `dubbing_style.json`；診斷寫入 `dubbing_timing.json` 與每句 `dub_timing`。

## 真實 API 實測後追加修正

- Replicate SDK 自訂 HTTPX transport 使環境代理未生效，實测音訊上傳回報 DNS 失敗；已補上代理／`NO_PROXY`，之後成功取得人聲與伴奏。TLS 驗證維持開啟。
- 所有 key 額度用盡後，原輪替器會重新選取已停用 key；現在明確停止，避免重複打無效請求。
- OpenAI Responses 回傳空白仍可能消耗推理 tokens；現在在判斷是否改走 Chat Completions 之前記錄用量。逾時、連線錯誤、限流不再觸發第二種協定生成。
- ASR、翻譯與審稿用量加入非機密的設定欄位標籤，UI 顯示每個 key 的本趟輸入＋輸出 tokens；這不是帳號每日剩餘額度查詢。每次成功回應立即追加 `api_usage.jsonl`，即使程序中途退出，也保留已回報的明細；遠端成功但本機未收到回應的費用仍需對照供應商帳單。
- 修正分離成功後仍遺留伴奏暫存 WAV 的清理。
- 聲線庫使用 MFCC 備援算法時重用同類型快取，避免每片反覆重建聲紋。媒體樣本下載不再附帶 Fish API Authorization；只有官方模型 API 請求帶帳號驗證。

- 針對實測中書面化／壓縮失真的譯文，縮減英文 few-shot 與過往題材提示，改用角色意圖、自然口語、完整問答和笑點的通用審稿準則。縮句請求同時提供中文原句；模型回覆維持原譯或重複相同不合格候選時，保留原譯並交給審稿，不連續重問五次。實測還发现句首大寫縮寫被誤認成人名而拒絕縮句；已取消僅憑大寫判斷人名的自動拒絕，專名依本片詞彙表與上下文審稿保護。

- 配音後審稿不再只准修正預設旗標：即使時長合格，也要檢查錯義、漏句、口語和笑點。引號清理只移除成對外層引號，保留台詞內部引用。

## 尚未驗證／限制

- 真實動畫完整約 7 分鐘尚未全片翻譯驗收；開頭 50 秒與先前續段包含人工校訂。最新 00:50–01:50 已完成無人工改稿的自動重跑，但仍有 2 卡延遲超標，不能稱為全自動品質通過，亦未證明其他未見影片都適用。
- 很短空檔仍可能產生無依據的 ASR 台詞；取樣字幕未必能發現所有問題。配音後審稿目前依文字與音檔時長，沒有逐音素強制對齊或嘴型分析。
- 瀏覽器視覺與互動驗證：瀏覽器無法訪問執行環境本機網址。已驗證 Gradio 建構、HTTP `/config` 和關鍵回呼，但不等於完成畫面驗收。
- Windows / macOS 實機、長片壓力、真實聲線下的呼吸／尾韻，以及笑點和角色表演的主觀品質。
- 原專案仍有其他語言品質啟發式；本次移除高風險的跨題材自動判定，沒有把全部 NLP 規則一次重寫。
- UI 成本為估計值；Replicate 分離目前以請求經過時間估算，與供應商實際 GPU 秒數可能不同，不能代替帳單。逐請求回報的 tokens 與未完成請求仍應對照供應商紀錄。
