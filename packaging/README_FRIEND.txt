Lovesnow-translate（給朋友）
============================

這是雲端配音／翻譯工具。解壓後點「啟動 Lovesnow.bat」就能開。
不需要另外裝 Python。Windows 10／11 64 位元即可。

第一次
------
1. 把整個資料夾解壓到桌面（不要只解出裡面幾個檔）。
2. 雙擊「啟動 Lovesnow.bat」。
3. 若 Windows 說「無法辨識」或 SmartScreen 擋下來：選「仍要執行」。
4. 等黑色視窗出現後，瀏覽器會打開 http://127.0.0.1:6006
5. 先到「API 設定」填這三把金鑰並按儲存（金鑰只存在這台電腦的 .env，不會上傳）：
   - OpenAI API Key（辨識、翻譯、審稿）
   - Fish Audio API Key（配音）
   - Replicate API Token（人聲分離）
6. 再到「一鍵自動化」上傳影片或貼網址。

關掉
----
關掉那個黑色視窗就會停止。不要關瀏覽器分頁就算停。

注意
----
- 需要網路。運算在 OpenAI／Fish／Replicate，費用算在你自己的帳號。
- 不要把填過金鑰的資料夾再傳給別人。
- 成片在 videos\劇名\ 裡。
- 若 6006 埠被佔，先關掉上一份黑色視窗再重開。
